# 可续研的记录

在当前对话或用户指定的位置保存一份简短状态。按任务需要选用这些栏目。已有记录时沿用原定位，在修订处注明变动。

- **任务**　用户要理解、选择或创作什么；已知范围、资料与预算。
- **地图与分支**　目前采用的组织方法、关键遗漏、各分支的状态（暂定、可收敛、受阻）。
- **关键判断与依据**　主张｜来源和位置｜实际阅读范围或数据口径｜支持、挑战或仅为线索｜仍未知什么。
- **修订**　原判断 → 哪条新材料触发变化 → 新判断；列出受影响的分支。
- **交接**　停止原因；下一份值得找的材料、可能改变的判断和重启条件。

续研时读取上次交接，核实会随时间变化或依赖特定版本的证据。将新材料接到对应主张，追踪受影响的结果；原材料仍适用时可沿用其定位。
